Glossary

Words used on this site

Each word is explained in one or two plain sentences.

Law

Bar exam
The licensing exam that a person must usually pass before practising law in a US state.
MBE (Multistate Bar Examination)
The multiple-choice part of the bar exam that most states use. It covers subjects such as contracts, torts, criminal law and constitutional law.
Precedent
An earlier court decision that later courts follow when they decide a similar case.
Overruled precedent
A court overrules a precedent when it decides that courts should no longer follow the earlier decision.
Good law
A rule or decision that courts still follow. Lawyers must check this before they rely on a case.
Citator
A tool that tells a lawyer whether a decision has been overruled or questioned. The project built a simple one from the government's table.
Dissent
The opinion of a judge who disagreed with the decision of the court. A dissent is not the rule of the case.
Statute
A written law passed by a legislature, such as Congress or a state legislature.

AI and search

AI model
A computer program that has learned patterns from a very large amount of text and can answer questions in writing.
Parameters
The numbers inside a model that it learned in training. More parameters usually mean a more capable model. The models in this project have 8 billion, which is small.
Law library
On this site, a large collection of legal texts that the model may read: a legal encyclopedia (Wex, from the Legal Information Institute at Cornell), court opinions, or both.
Retrieval, or search
Finding the passages in a large collection that are most likely to help with a question. A search engine does retrieval.
RAG (retrieval-augmented generation)
A method with two steps. First a system searches for passages. Then it gives them to an AI model together with the question.
BM25
A classic search method that counts matching words. It gives more weight to rare words.
E5
A small AI model for search. It compares the meaning of a question with the meaning of each passage.
Gold passage
The passage that a law student marked as the one that answers a question.
Agent
An AI model that can take steps on its own, such as searching, reading a passage or checking a case, before it answers.
Silver label
A label made by an AI model. The project never calls these expert labels or human labels.

Research and statistics

Preregistration
A plan that researchers fix before they see their results. It names the tests and what counts as success, so that nobody can pick the favourable tests afterwards.
Percentage point
The difference between two percentages. Going from 40% to 45% is a rise of 5 percentage points.
Uncertainty range (95% interval)
A range of plausible values for the true difference, given how much a result could vary by chance. If the range includes zero, we cannot rule out “no difference”.
Correction for many tests (Holm correction)
When you run 11 tests, one may look good by luck. The correction makes each test harder to pass, to allow for this.
Supported, not supported
A claim is supported when the effect is big enough, the uncertainty range stays on one side of zero, and the claim passes the correction. “Not supported” does not mean “proven false”.
Reproduce
To repeat an earlier study and see whether the same numbers come out.
Run file
A file that records one run of an experiment: the settings, the versions of the code and the data, and the result for each question.
Checksum
A short code computed from a file. If even one character of the file changes, the code changes. It lets you check that a download is unchanged.
