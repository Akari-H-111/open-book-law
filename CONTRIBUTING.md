# Questions, corrections and contributions

Thank you for reading Open Book. This project was made mostly by AI models, and no person has checked the results yet. So reports of mistakes are very welcome.

## If you teach or study with it

Open an issue on GitHub and say which page or file you mean. Useful reports are:

- a sentence that students did not understand;
- a result on the website that does not match [`docs/RESULTS.md`](docs/RESULTS.md);
- a mistake in an AI-written question in [`docs/review/goodlaw_sample.md`](docs/review/goodlaw_sample.md).

You do not need to know how to program.

## If you want to check or change the code

1. Read [`docs/ENGINEERING.md`](docs/ENGINEERING.md). Level 1 rebuilds every result in a few minutes.
2. Before you open a pull request, run the tests and level 1. Level 1 must end with `Same results: yes`, unless your change is meant to alter a result.
3. Keep the rules of section 8 of the engineering guide. In short: never edit a run file, never add exam question text or passage text, and take every number from a script.
4. Write for readers who are not specialists: short sentences, plain words, and an explanation for each new term.

A change to a test or to its threshold belongs in [`docs/PREREGISTRATION.md`](docs/PREREGISTRATION.md) as a dated amendment, before the run that it affects.

## What this project cannot help with

It is not legal advice, and nobody here can answer questions about a real legal problem.
